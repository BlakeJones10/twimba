# Twimba - Twitter Clone

A lightweight Twitter clone built with vanilla JavaScript that allows users to create tweets, reply to tweets, like, and retweet.

## Features

- 📝 Create new tweets
- 💬 Reply to existing tweets
- ❤️ Like/unlike tweets
- 🔄 Retweet/unretweet posts
- 🗑️ Delete replies
- 📱 Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- UUID for generating unique IDs
- Font Awesome for icons

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/yourusername/twimba.git
```

2. Open the project folder:
```bash
cd twimba
```

3. Open `index.html` in your browser or use a local server.

## Usage

- Click the tweet button to create a new tweet
- Click the reply icon to view and add replies
- Click the heart icon to like/unlike
- Click the retweet icon to retweet/unretweet
- Click delete to remove replies
